# APP-033｜自動印刷までの実用版候補（v0.7.0-rc.1）と実機検収

2026-11-22 JST作成。Windows 11 + Canon MF244dw向け。**本書作成時点では実紙印刷が未検証**である。Release Candidate (RC) と正式完成版を区別する。

## 目的・完成する動線

MF244dw本体で「コピー/スキャン」→「スキャン」→「PC」→「スタート」したJPEGを、Windowsが新着検出→黒・暗灰背景除去→必要なら0/1/2/3/5mm追加カット→回転・A4配置→Windows印刷キューへ**最大1回**送信する。

通常の監視はPC操作なしで継続する。ただし、**初回の1枚だけは手動試し刷りと実紙確認が必要**。この許可はアプリを再起動すると解除される。

## 自動印刷の許可ボタン（v0.7.1-rc.1）

履歴の下に「**自動印刷の準備：左から①→④の順に操作**」という枠を設け、ボタンを横一列に整理した。

1. **① 1枚試し刷り**：`READY_REVIEW`の画像を選び、現在の回転・DPI・A4配置・内側カット量に一致するプレビューを用意してから押す。
2. **② 紙の結果を確認**：実際にCanonから排出された紙を目視確認して押す。送信しただけでは許可しない。
3. **③ 自動印刷を許可**：実紙が正常だった場合にのみ押せる。確認ダイアログで承認する。
4. **④ 監視開始（自動印刷）**：明示的に許可した後に押せる名称へ切り替わる。以後の新規JPEGを無人印刷へ送信する。

許可前は④の位置に「**監視のみ開始（印刷OFF）**」が表示され、従来どおり安全にスキャンの加工だけを試せる。すでに監視中なら、同じ枠の下の「**監視を停止（準備へ戻る）**」を押してから①〜③を行う。

ボタン下の案内は現在の状態に合わせて変化する。試し刷りの送信中、紙の確認待ち、許可済み、監視中であることが分かる。**権限ゲートの手順・監視停止時の許可失効・再起動での許可失効は従来どおり**。

## Canon MF Scan Utility側の設定

- 「カラースキャン」等の保存形式を **JPEG** に設定。PDFはこの監視機能の対象外。
- **「今日の日付のフォルダーに保存する」をOFF**にする。現行監視は指定受信フォルダの直下だけを扱い、サブフォルダを再帰探索しない。
- PC受信フォルダ（スキャンJPEG保存先）と加工結果の出力先は別フォルダにする。
- Canon側とアプリの読取DPI（例：300）を一致させる。原稿の原寸はDPIが正しくない場合は保証できない。

## 最初の設定と紙の検収

1. 修正EXEのタイトルが `黒カット印刷 v0.7.0-rc.1 | APP-033` であることを確認。
2. 印刷先にWindowsのCanon MF240/MF244系キューを明示選択。候補が自動表示される場合も名前を確認する。**「Microsoft Print to PDF」は選ばない**。
3. 受信・出力フォルダを選ぶ。固定回転、読取DPI、A4`nominal/fit`、追加の内側カット`0/1/2/3/5mm`を設定。
4. 手動試し刷りに使用する原稿を`READY_REVIEW`履歴から選択。旧版の画像や、現在の回転/倍率/内側カット/DPIと異なるプレビューは**試し刷りから自動印刷許可に進めない**。現在の設定で「選択原稿を再加工（印刷なし）」して新しいプレビューを作る。
5. 「選択したプレビューを開く」「検出境界を見る」で本文・ページ番号・図版が残ることを確認。0mmと1mm（必要なら2/3/5mm）を比較。追加カットがスキップされた場合はその旨表示。
6. 監視OFFで、`READY_REVIEW`を選択し「選択した原稿を1枚試し刷り」を押す。確認画面のプリンター名を見て許可する。
7. **実際にCanonからA4・白黒・片面・1部が排紙**され、回転、倍率、文字、余白、図版が正常であることを確認してから「紙の結果を確認」へ進む。出なければ「いいえ」を選ぶ。
8. 合格した場合のみ「自動印刷を許可」を押し、内容を確認して「監視を開始」を押す。これ以降は**新規JPEGのみ**がPC操作なしで最大1部ずつ送信される。

## 無人印刷の動作と失敗時

- スキャン完了まで待ち、JPEGのサイズ・更新時刻が安定し、画像として読み込めることを確認して処理する。既にあった原稿は監視ON時に印刷しない。
- `READY_REVIEW`：加工完了・印刷OFF。`HOLD`：検出不確か・深く切り過ぎ・停止などにより印刷せず保留。`SUBMITTED`：Windowsスプーラーへの送信を受理した可能性（**排紙成功ではない**）。`UNKNOWN`：送信結果が不確か。**自動再送しない**。
- 通知領域（トレイ）の「監視を停止」または画面の「停止」で、新規受付と無人印刷許可を解除する。終了・再起動後も監視OFF、自動印刷OFF。
- 途中でプリンター停止・印刷失敗・不明状態があれば、重複印刷防止のため元ジョブを自動再送しない。プリンターの紙とWindowsの印刷キューを人が確認する。
- 設定変更で過去の試し刷り承認を失効する。回転、倍率、DPI、追加カットを変更した後は新設定のプレビューで再度1枚試し刷りが必要。
- 強い内側カットではページ番号や端の文字・図版まで失う可能性がある。事前のプレビューの目視確認が不可欠。

## 実装上の保証範囲

- 印刷先の候補表示はUIだけの機能であり、それ自体が印刷許可にならない。
- Windowsユーザーの実紙確認がない状態では自動印刷へ移行できない。
- プレビューの`report.json`を使い、手動試し刷り画像の回転/DPI/`nominal/fit`/内側カット値と、現在設定の一致を確認する。
- 元のJPEG、旧ジョブ・履歴は更新しない。新しいプレビューを別ジョブとして保存する。
- 印刷処理は`app/windows_print.py`でWindows GDIを使用し、選択したキューのA4/白黒/片面/1部を要求する。キュー既定設定は書き換えない。
- Windows APIのモックテストとCIビルドは、Canonから現実の紙が出ることを保証しない。
