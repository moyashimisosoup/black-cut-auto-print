# APP-033 / M6｜内側カット量（除去の強さ）設定

版数：**v0.6.2-preview.1**（Windows実紙印刷は未検収）
依存：Draft PR #6（v0.6.1プレビュー）からの差分

## できること

検出した紙面マスクを基準に、上下左右の端を**追加で内側へ切る**程度を選べます。現在の赤い検出輪郭は「推定紙面」、追加カット後の緑の輪郭は「**印刷プレビューに実際に残す範囲**」です。

| 選択 | 期待する使い方 |
|---|---|
| **0 mm（既定）** | 従来処理と同じ。最も保守的 |
| 1 mm | 影や黒い縁が薄く残る場合 |
| 2 mm | もう少し深い端の除去 |
| 3 mm | 本の厚み・端の影が目立つ場合。文字欠けに注意 |
| 5 mm | 強い処理。ページ番号、見出し、図版の端も切れる可能性がある |

選択値は**元画像の読取DPIを基準**にピクセルへ換算して反映します。実際の紙の寸法が違えば距離も違うため、Canon側のスキャン解像度とアプリの「読取DPI」は一致させてください。

### 操作

1. 自動印刷をOFFにして、監視を停止。
2. 履歴から以前の`READY_REVIEW`原稿を選ぶ。
3. 「追加の内側カット」を **0 → 1 → 2 → 3 → 5mm** の順に比較。まず1～2mmを試す。
4. 「選択原稿を再加工（印刷なし）」を押す。元画像・旧ジョブは変更せず新規プレビューを記録。
5. 新しい履歴を選んで「選択したプレビューを開く」。本文、ページ番号、イラストが切れていないか目視確認。
6. 「検出境界を見る」で**赤線＝元の推定輪郭／緑線＝深めに残した輪郭**を比較。0mmや古いジョブには緑線がない。
7. 正しい回転角・A4縦横・fit/nominal・追加カットmmは履歴の設定表示で確認。
8. 実際の紙に印刷する場合は、必ず一枚の手動試し刷りと本人の紙面確認を行い、その後にのみ自動印刷を許可する。

### 制限と安全条件

- 内側カットは**四辺一律**で、局所的に黒い筋だけをAIで消すものではありません。本文の外側だけを識別する保証はなく、5mmを指定すると重要な内容まで消えることがあります。
- 誤切除を検出する一般的なOCR判定はありません。**最終的な可否は元画像・プレビューの目視比較**が必要です。
- カットが強すぎて紙面マスクが70%未満になる場合は**`HOLD`で印刷をしません**。
- 真っ白な背景など紙面境界を特定できない場合、追加カットは**スキップ**し、レポートに理由を記録します。
- 設定を変更すると、その起動中に得た手動試し刷り確認に基づく無人印刷許可は失効します。再加工はプリンターAPIを呼びません。
- 起動時の監視・自動印刷はOFF。前回の自動印刷許可は保存・復元しません。
- `paper_mask.png`は追加カット後のマスクに置換。診断用`boundary_overlay.png`は従来の赤線を維持し、追加カット時のみ`trim_boundary_overlay.png`を保存。
- これまでのCanon実機画像で今回の効果を検証したわけではありません。CIは合成画像のみ、Canonでの印刷は未確認です。

### 内部構成

- `app/m1_processing.py`：`trim_paper_edges(mask, trim_mm, source_dpi)`、mm→px換算と内側マスク縮小。
- `app/m2_monitor.py`：フォルダ監視での固定設定伝播、CLI`--trim-mm`。
- `app/m6_preview.py`：旧原稿の印刷なし再加工。
- `app/m4_operator_ui.py`：mm選択、画面上のリスク注意、履歴で使用値を表示。
- `tests/test_m6_trim.py`：多方向、文字/中央保持、過剰トリムHOLD、明るい原稿の保護。
