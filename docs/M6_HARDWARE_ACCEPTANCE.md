# APP-033 / M6 実機受入検査シート（検査未実施）

2026-11-22 JST作成。Canon MF244dw、Windows 11、M5 Windowsトレイ評価版の検収に使用する。実施前に[最新CHECKPOINT](checkpoints/APP033_M5_TRAY_20261122.md)と[M5操作ガイド](M5_TRAY_SETUP.md)を確認する。

**原則：最初は印刷OFF。** 失敗時はアプリの画面・SQLite/診断レポートから原因を追う。紙が出たか不明なジョブを自動再送しない。現物スキャン画像をPublic Repoにアップロードしない。

## 準備

- [ ] Canon純正アプリで、本体の「スキャン→PC→スタート」からWindowsの専用フォルダへJPEGが保存される。
- [ ] Canon MF244dwの通常のWindows印刷ができ、A4の用紙がセットされている。
- [ ] アプリの受信フォルダと保存先を別フォルダにし、出力先に過去のジョブが混在しない。
- [ ] M5評価用EXEを出所確認してWindowsで起動。初期状態が「監視OFF」「自動印刷OFF」である。

## A：画像処理と保存（**まだ印刷OFF**）

最低5枚の実スキャンを用意する。書籍など著作権のある内容はユーザーのPC内にとどめる。

| ケース | 期待する結果 | 結果 |
|---|---|---|
| A1 右・下が暗い見開き | 外側の暗背景のみ白化、綴じ目・図版を保持 | 未 |
| A2 四辺すべてが黒・濃灰 | 上下左右の外側を白化、本文欠けなし | 未 |
| A3 上だけ／左だけ暗い | 紙面の輪郭を誤って切らない | 未 |
| A4 古い本の黄ばみ・影 | 原稿色を過度に変更せず、難しければHOLD | 未 |
| A5 白紙に近いもの・黒ベタ図版を含む | 文字・写真・図版内部の黒は保持 | 未 |

- [ ] 「監視を開始」後、原稿3枚を**連続**してスキャンし、別々の履歴となる。
- [ ] 各件の`cleaned.png`・`a4_preview.png`・`boundary_overlay.png`を比較。A4配置、回転、文字欠け、原稿端の白黒を確認する。
- [ ] 誤検出が疑われる場合はHOLDになる。必要なら具体例と診断数値だけを共有し、画像本体は非公開で扱う。

## B：タスクトレイ・停止

- [ ] 監視ONで最小化すると、トレイに入り、スキャンを継続して検知する。
- [ ] 「画面を表示」で復帰できる。
- [ ] 「監視を停止」で受付が止まり、自動印刷許可がOFFになる。
- [ ] アプリ終了・再起動後は監視OFF・自動印刷OFF。旧ファイルの再処理は発生しない。

## C：手動で1枚だけ試し刷り（**ここから実際に印刷される**）

- [ ] 監視を停止し、履歴から`READY_REVIEW`の正しいA4画像を選択。
- [ ] Windowsプリンター一覧から正しいCanonキュー名を選び「選択した原稿を1枚試し刷り」を押す。
- [ ] MF244dwから**A4・白黒・片面・ちょうど1部**が出る。
- [ ] 文字・図版・綴じ目・原稿の縁が切れていない。余白、回転、縮尺が意図に合う。
- [ ] すべて成立した場合にのみ「紙の結果を確認」で成功と回答。そうでなければ不合格で停止。

## D：無人印刷の安全試験（C合格後のみ）

- [ ] 「自動印刷を許可」で確認後、監視をONにして新規原稿を1枚スキャン。PC操作なしで1枚だけ出力される。
- [ ] 監視開始前の画像は印刷されず、同じファイルイベントは二重印刷されない。
- [ ] 監視停止で印刷許可が解除される。再起動しても勝手に再許可されない。
- [ ] プリンターがオフライン等の状態では、アプリは無条件の再送をしない。状態が`UNKNOWN`なら実際の紙・印刷履歴を人が調べる。

## 検収判定

- **PASS**：A〜Dの必須項目を実機で確認し、A4・1部と停止・再送禁止が成立している。
- **HOLD**：未実施項目がある／画質・余白・倍率に問題がある／プリンター送信結果が不明。
- **FAIL**：誤印刷、重複送信、原稿欠け、許可していない送信が発生した。無人印刷をOFFのままにし、修正・再試験が必要。

未実施のままチェックを付けない。検収結果はWindows端末・プリンタードライバー・アプリの実際の事実に基づく。合格後にのみ[依存Draft PR #1〜#4](https://github.com/moyashimisosoup/black-cut-auto-print/pulls)を順にレビューしてmain統合、正式配布を検討する。
