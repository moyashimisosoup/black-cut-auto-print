# APP-033｜M6 画像方向・A4配置・再加工プレビュー

2026-11-22 JST。対象：Canon MF244dwで保存されたJPEGの加工プレビュー改善。**Windowsの実印刷結果は未検証です。**

## 今回対応したこと

1. **再スキャンせず回転を試す。** アプリの履歴にある原稿を選び「選択原稿を再加工（印刷なし）」を押す。設定中の回転0/90/180/270度と読取DPIを適用し、新しい`READY_REVIEW`プレビューを作る。
2. **A4配置を選択する。** `nominal`は元のDPI（設定値または画像メタデータ）を基準に、原寸を超えない倍率を使う。`fit`は余白5mmを確保しつつA4の印刷領域に拡大・縮小する。用紙方向（縦・横）は**回転後の紙面の縦横比**で決める。
3. **印刷の許可を維持しない。** 再加工は`app/m6_preview.py`で行い、Windows印刷APIを呼ばない。元JPEG・過去の履歴を変更せず新しいジョブIDとA4プレビューを記録する。回転/DPI/配置設定を変えると手動試し刷りによる自動印刷の許可は失効する。
4. `report.json`に`rotation_degrees`、`scale_mode`、`a4_orientation`を追加し、判断を再確認できるようにした。
5. 合成画像テストとTk仮想画面テストを追加。M5のWindows EXEのビルド定義に組み込んだ。

## バージョンと処理済み画像の設定確認

`v0.6.1-preview.1`以降はウィンドウタイトルと画面見出し、トレイで版数を表示する。新旧EXEを取り違えた場合はタイトルから確認できる。

履歴の原稿を選ぶと、プレビュー画像に**実際に適用された**回転角（反時計回り）、A4縦横、`nominal`/`fit`を表示する。画面上で選択している回転設定を変えても、以前に生成済みのプレビューには反映されない。表示が「旧版のため適用設定は不明」の場合は、旧画像を印刷OFFで再加工して新しい履歴の情報を確認する。

## ユーザーが確認する操作

1. 新しい評価版を起動し、通常どおり**印刷OFF**で受信履歴を表示。
2. 既存の`READY_REVIEW`原稿を選択する。
3. 「固定回転」を`90`、A4配置を`nominal`にして**監視を停止した状態**で「選択原稿を再加工（印刷なし）」を押す。再スキャン不要。
4. 生成された新しい履歴の`READY_REVIEW`を選び、プレビューを開く。向きが逆なら`270`を指定してもう一度再加工。
5. 画像が小さくて読みづらい場合のみ`fit`を試す。拡大は文字を大きくできるが、**解像度・精細さそのものは増やさない**。
6. 原稿の最上部・最下部の余分な影や本の厚みは、画質の違いを見ながら確認する。現段階で**本文を巻き込む危険のある自動トリムは入れていない**。

## 未実装の自動判定

- **本文の正立方向の全自動判定は未実装。** OCRなし・文字解析なしでは縦横比だけから0/90/180/270度の正しい向きを確定できない。横長A4の選択と文字方向の推定を混同しない。
- 本のページの外側に見える綴じ目・本の厚みの影を、すべて自動で安全に削るのも未実装。加工済みプレビューのスクリーンショットだけでは紙面の正確な境界を確定できず、元の高解像度スキャンによる局所的な診断が必要。
- DPIの元データが誤っている場合は原寸を保証できない。画面で確認のうえ、Canon実機で1枚試し刷りするまで自動印刷をONにしない。
