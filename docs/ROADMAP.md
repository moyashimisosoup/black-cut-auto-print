## M1：画像処理PoC（最優先）
**成果物**：画像1枚入力→紙面境界の可視化→外側白化→A4プレビューの最小CLI/小さなUI。印刷送信は行わない。

- [x] 初期候補推定（適応的Otsuしきい値＋連結領域＋凸包＋形状/輝度差ゲート）。エッジ検査・複雑な形状への耐性は今後の改善事項。
- [x] 上下左右個別・四辺暗背景、暗灰、白枠、綴じ目を合成画像でテスト（限定条件）。
- [ ] 画像端接触と湾曲・実原稿のバリエーションを十分に検証する。
- [x] 紙面保持マスク内の元のRGB画素を維持し、マスク外を白化する。
- [x] 候補不足、低明暗差、複数領域、暗色全面等でHOLDを返す基本ゲート。文字欠けの偽陰性はなお検証が必要。
- [ ] 仕様書§12.1の画像検出ケースを、合成テスト素材とローカル実スキャンで確認。
- [x] 元DPIが不明なら仮定300dpiの警告をreport.jsonに記録。A4中央・拡大せず配置する。

**合格ゲート**：紙面内の本文・図版を切らないこと、暗い外周がA4印刷に乗らないこと、失敗時に無人印刷されないこと。

## 実装時の判断指針
1. 最初から自動印刷に結びつけず、M1で画質を確認する。
2. 変更は小さく保ち、存在しない検証結果を「合格」と記さない。
3. 実スキャン画像はPublic Repoへ追加しない。合成画像のみ共有可能。
4. ユーザーの使用感に基づいて設定を増やす。自動分割・OCR・複雑な編集画面は後回し。
