# APP-033/M3｜プレビュー専用Windowsアプリ

状態：Draft PR。2026-11-21現在、**自動印刷は実装していない**。M2のWindows実機試し刷りと画像の目視検収が済むまで印刷を有効化しない。

## 操作
1. Canon MF Scan Utilityで、印刷自動化専用の保存フォルダ（JPEG、推奨300dpi）を用意する。
2. Windows用 `BlackCutPreview.exe` を実行する（ビルド成果物が生成された場合）。または、Pythonで依存を入れて `python app/m3_preview_ui.py` を実行する。
3. 「スキャン受信フォルダ」にCanonの専用フォルダを、「加工画像の保存先」には**別のフォルダ**を指定する。保存先を受信フォルダの内側にしない。
4. 「画像の回転」（0/90/180/270度、反時計回り）を選ぶ。スキャン原稿に合わせて設定する。
5. 「監視を開始」を押す。現在の受信フォルダにあるJPEGは**処理されない**。新しくスキャンしたJPEGのみ受け付ける。
6. MF244dw本体でスキャン→PC→スタート。画面に `READY_REVIEW` または `HOLD` が表示される。
7. `READY_REVIEW` の場合「直近のA4画像を開く」から出力を確認する。**プリンターには一切送信しない**。
8. 終了時は「停止」を押す。アプリを閉じる場合も監視処理が終わるまで終了を待つ。

## 保存先・確認ポイント
- `<保存先>/jobs/<ジョブID>/a4_preview.png`：A4白黒配置
- `<保存先>/jobs/<ジョブID>/cleaned.png`：黒背景を白化した原画
- `<保存先>/jobs/<ジョブID>/boundary_overlay.png`：境界診断
- `<保存先>/jobs.sqlite3`：受信履歴・状態
- `%APPDATA%/BlackCutPreview/settings.json`：受信・保存フォルダと回転設定（PC内のみ）

## 安全に関する注意
- **このプレビュー版には印刷ボタン、印刷送信、印刷ONの設定はない**。M2のコマンドライン試し刷りとは別。
- アプリはタスクトレイ常駐ではない。画面を閉じると監視も止まる。起動時自動監視はしない。
- 既定プリンターやWindowsの印刷設定を変更しない。Windowsのプリンターとは接続しない。
- 一般公開のリポジトリへ実原稿・教材・私的な画像・結果フォルダをアップロードしない。
- CIで構築したexeは原則未署名。OSが警告を表示した場合、出所を確認し、不明なファイルを無理に実行しない。
- Windows実機での画面操作・フォルダ選択・Canonスキャン受信・EXE起動はまだ未検収。CIのWindowsビルド成功は実機合格を意味しない。
