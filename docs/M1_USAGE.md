# M1画像処理PoC｜実行・確認ガイド（印刷機能なし）

APP-033／実装初稿：2026-11-21 JST。仕様正本：[v0.3](spec/BLACK_CUT_AUTO_PRINT_SPEC_v0.3_20261121.md)

## 目的
スキャン画像を1枚読み、紙面境界の候補を抽出し、**紙面外側だけを白化**した画像とA4プレビューを生成する。四辺すべての黒背景にも対応することを目指す。**このM1にはフォルダ監視・プリンター操作・自動印刷機能は存在しない。**

## 動作環境
Python 3.13または互換バージョン。Windows、macOS、Linuxで処理コードの試用は可能。Windowsへのプリンタ連携はM2以降。

```powershell
python -m pip install -r requirements-m1.txt
python app/m1_processing.py "C:\\path\\to\\scan.jpg" --output "C:\\path\\to\\result01" --rotate 90 --output-dpi 150
python -m pytest -q tests/test_m1_processing.py
```

- `--rotate`：0/90/180/270。既定0。文字の向きは自動判定しない。90は反時計回り。
- `--output-dpi`：150または300。既定150は確認用であり、実機印刷想定の品質評価では300を選ぶ。
- `--source-dpi`：元画像のDPIが不明なとき任意で指定。未指定なら300dpi**仮定**。物理原寸は保証しない。
- `--output`：試行ごとに別フォルダを指定することを推奨。既存の出力名は上書きされるため、重要なファイルを置かない。

## 成果物
- `boundary_overlay.png`：原画に候補紙面輪郭を赤線で重ねる診断用。
- `paper_mask.png`：白＝紙面保持範囲、黒＝外側背景。
- `cleaned.png`：原画の紙面内部のRGB値を保ち、外側だけ白化。ACCEPT時のみ。
- `a4_preview.png`：グレースケールのA4中央配置。ACCEPT時のみ。
- `report.json`：`status` がACCEPT/HOLD、`reason`、検出矩形、推定輝度差など。

**重要：M1のACCEPTはアルゴリズムの内部判定であり、人間の実画像検収・自動印刷許可を意味しない。** 文字欠け・外周の影・倍率を目視で確認する。

## 既知の制約
1. 見開きの強い曲面変形、反射、影が内側に入り込む場合は紙面の輪郭が不確実になり得る。
2. 明るい背景と明るい紙面、暗色の紙面、2つ以上の独立明領域などではHOLDまたは誤検出の可能性がある。
3. 傾きは現段階では補正しない。紙面の輪郭の検出・保護を優先する。
4. 複雑な背景、文字が外縁いっぱいにある原稿等はまだ試験不足。M1試作は無人印刷の本番ゲートを通過していない。
5. `--source-dpi` と画像の実解像度の違いで、A4上の表示サイズは変わる。添付画像はDPIメタデータがなく、仮定300dpiで小さく配置される場合がある。
