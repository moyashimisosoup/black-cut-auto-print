APP-033 | Windows EXE Update Pack | Folder path validation fix

このZIPは、既存のWindows評価版EXEを更新するためのパッケージです。
差分のPythonソースを既存PyInstaller EXEの中へ直接書き込むことはできないため、
「更新適用バッチ」が新しいEXEを検証して安全に差し替えます。管理者権限は不要です。

【更新内容】
・D:\ScanInbox のような受信フォルダに対して、結果保存先 D:\ を許可します。
・同じ受信フォルダ自身、および受信フォルダ内部を結果保存先に指定することは引き続き禁止します。
・スキャンや印刷の安全条件は変更していません。起動時は監視OFF・無人印刷OFFです。

【適用手順】
1. ZIP内のファイルを全部、既存EXEとは別のフォルダに展開する。
2. 黒カット印刷アプリを終了する。通知領域（トレイ）のアイコンも「終了」する。
3. 以前ダウンロードした EXE ファイルを apply_update.bat にドラッグ＆ドロップする。
   または apply_update.bat をダブルクリックし、元のEXEのフルパスを入力する。
4. 検証が通った場合、画面に UPDATE と入力してEnterを押す。
5. 元のEXEが同じ場所で更新され、古いファイルは .backup-before-APP033-path-fix.exe として残る。
6. 更新したEXEを手動起動し、まず「監視開始」のみを確認する（印刷はOFF）。

【安全対策】
・新旧EXEのSHA-256を照合します。対応するM4/M5初期評価版以外は変更しません。
・EXEが起動中でロックされている場合は停止し、勝手にプロセスを終了させません。
・更新前に旧EXEをバックアップします。失敗時は可能な限り自動復元します。
・設定フォルダ、スキャン画像、SQLite履歴、プリンター設定は更新対象外です。
・EXEの自動起動や自動印刷の許可はしません。
・旧EXEと同じフォルダに新EXEを展開すると適用できません。必ず別フォルダに展開してください。

【ファイル】
BlackCutPrintTrayCandidate.exe : 修正版Windows評価版
apply_update.bat               : 更新バッチ（ダブルクリック/旧EXEをドラッグ）
apply_update.ps1               : SHA検証・バックアップ・更新・失敗時復元
new_exe_sha256.txt             : 新しいEXEのSHA-256
UPDATE_README.txt              : この説明書

【更新が適用できない場合】
旧EXEのファイル名・SHAが認識できない場合、勝手に書き換えません。
その場合は、ZIP内の BlackCutPrintTrayCandidate.exe を別の場所で起動し、
受信・保存フォルダを設定して動作確認してください。旧EXEは削除しません。
